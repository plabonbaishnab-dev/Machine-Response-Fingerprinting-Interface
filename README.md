# Smart Park - IoT Smart Parking System

Smart Park is a real-time smart parking monitoring system designed to improve urban parking management and reduce traffic congestion. The system uses sensor-based slot detection connected to an Arduino microcontroller and displays live parking availability through a web-based dashboard.

This project demonstrates how IoT hardware can be integrated with a web application to provide real-time monitoring and intelligent parking management.

---

## Features

• Real-time parking slot monitoring  
• Live dashboard showing available and occupied slots  
• Automatic log tracking for parking activity  
• Sensor-based slot detection using Arduino  
• Web interface built using Flask, HTML, CSS, and JavaScript  
• Responsive and interactive dashboard UI  

---

## System Architecture


1. Sensors detect whether a parking slot is occupied.
2. Arduino processes sensor data.
3. Data is transmitted to the Flask backend.
4. The web dashboard fetches updates and displays the parking status in real time.

## Project Goal

Urban congestion is often caused by drivers searching for available parking spaces.  
Smart Park aims to solve this problem by providing real-time parking availability data to improve traffic flow and reduce unnecessary delays.
